### Общая информация (2–3 предложения)

```
Приложение заменяет бумажные ведомости в столовой: сотрудник подносит карту с
QR-кодом, терминал за две секунды показывает, кто это и положено ли ему питание
сейчас. Повторный проход в тот же приём пищи отклоняется автоматически, а все
записи уходят на сервер, где из них собираются отчёты по организациям и людям.
Столовая продолжает работать и без интернета — записи накапливаются локально и
отправляются сами, когда связь появится.
```

### Преимущества (не более трёх)

```
1. Проход за две секунды. Оператору не нужно искать человека в списке: достаточно
   поднести карту к сканеру.

2. Двойное питание исключается. Приложение само знает расписание столовой и не
   пропустит того, кто уже получил этот приём пищи сегодня.

3. Работает без интернета. Связь нужна только для обмена с сервером, раздача идёт
   в любом случае.
```

### Особые условия использования

```
Нужен внешний QR-сканер, подключённый к USB-порту терминала. Для синхронизации с
сервером и отчётов нужен интернет; раздача питания работает и без него. У каждого
сотрудника должна быть карта-пропуск с QR-кодом — они печатаются в серверной части
системы.
```

### Раздел «Как это работает»

```
Для кого

Столовые на производственных площадках, вахтовых посёлках и стройках, где
питание получают сотрудники нескольких подрядных организаций и его нужно
достоверно учитывать.

Как проходит раздача

1. Сотруднику выдаётся карта-пропуск с QR-кодом. Карты печатаются в серверной
   части системы, там же задаётся категория питания.
2. На раздаче оператор входит в приложение по своей карте.
3. Сотрудник подносит карту к сканеру. Приложение проверяет её по локальной базе
   и за две секунды показывает: кто это, из какой организации и засчитан ли проход.
4. Если человек уже получал этот приём пищи сегодня, проход отклоняется — на
   экране видно, во сколько он проходил.
5. Какой сейчас приём пищи — завтрак, обед, ужин или ночное питание — приложение
   определяет само по расписанию столовой и часовому поясу точки.

Что делать без интернета

Ничего. Приложение хранит справочник сотрудников и записи о проходах прямо на
терминале, поэтому раздача не зависит от связи. Когда интернет появляется,
накопленные записи уходят на сервер сами, а справочник сотрудников обновляется.
В журнале видно, какие записи уже синхронизированы, а какие ещё ждут отправки.

Отчёты

Отчёты собираются в серверной части: питание по дням и организациям, по каждому
сотруднику — сколько завтраков, обедов, ужинов и ночных приёмов, сколько дней он
появлялся в столовой. Выгрузка в Excel.

Что нужно для работы

• Смарт-терминал Эвотор 7.3
• Внешний QR-сканер в USB-порт терминала
• Учётная запись в системе учёта питания «СеверФудс» — адрес сервера и токен
  синхронизации выдаёт администратор; они вводятся один раз при первом запуске
• Карты-пропуска с QR-кодом у сотрудников

Установка и настройка

1. Установите приложение из Эвотор.Маркета.
2. При первом запуске укажите адрес сервера, токен синхронизации и часовой пояс
   точки — их выдаёт администратор системы.
3. Подключите QR-сканер в любой USB-порт терминала.
4. Войдите по карте оператора — приложение готово к раздаче.

Полная инструкция (использование и установка): https://severfoods.ru/manual-evotor.html — тот же файл нужно залить и на nrg.severfoods.ru, чтобы точки Нерюнгри открывали инструкцию со своего домена (ссылка в приложении строится из адреса сервера, на который настроен терминал).
```

### Тарифы

```
«Удалённая поддержка» — подписка 200 ₽/мес за терминал
```

Модель — подписка, а не разовая покупка: официальная рекомендация Эвотора —
подписка для приложений, «интегрирующих Эвотор со сторонними сервисами,
которые требуют поддержки и обслуживания» (наш случай — обращение к
своему серверу, обновления). Тариф создаётся и привязывается к `tariffId`
в личном кабинете dev.evotor.ru до публикации — после публикации тариф
изменить нельзя, только архивировать и завести новый.

Требование площадки — **паритет цен**: стоимость в Эвотор.Маркете не должна
отличаться от стоимости на вашем сайте и от цен на аналогичные приложения
(для сравнения: похожее по функции «Удалённый доступ к терминалу» в
Маркете стоит от 250 ₽/мес).

### Видео

Требуется ссылка на видео о приложении. **YouTube запрещён** — только RuTube или
VK Видео; версию с YouTube-ссылкой не пропустят на ревью.

Сценарий на 40–60 секунд, снять можно на телефон прямо у терминала:

```
1. Терминал с открытым приложением, крупно — экран сканера (5 сек).
2. Сотрудник подносит карту, на экране появляется зелёная карточка
   «Обед зафиксирован» с его ФИО (10 сек).
3. Тот же человек подносит карту второй раз — жёлтая карточка
   «Обед уже получен сегодня» (10 сек).
4. Экран «Журнал питания»: список проходов за день (10 сек).
5. Отключаем интернет, проводим ещё человека — проход засчитан;
   включаем обратно — записи ушли на сервер (15 сек).
```
