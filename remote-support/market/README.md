# Карточка приложения «Удалённая поддержка» для Эвотор.Маркета

Поля названы так же, как в кабинете [dev.evotor.ru](https://dev.evotor.ru).
Места, отмеченные `‹…›`, заполняете вы — этих данных у меня нет.

Отдельный продукт, не связан с карточкой СеверФудс — своя регистрация,
свой `app_uuid`, своя оферта.

---

## 1. Интеграция (проксирование запросов)

Вкладка **«Интеграция»** → флажок **«Проксирование запросов из приложения
с терминала на ваш сервер»** → включить, список разрешённых URL:

```
https://remote\.ntrip\.host/.*
```

Маска — регулярное выражение (точки экранированы обратным слэшем,
`/.*` в конце покрывает путь запроса, например `/api/heartbeat`) — без
этого получите `{"errors":[{"code":2003,"reason":"URL is not whitelisted"}]}`,
как уже бывало с СеверФудс. После изменения списка URL приложение нужно
заново «применить» к уже установленным терминалам через личный кабинет
покупателя (market.evotor.ru → «Мои приложения» → снять/поставить галочку
→ «Установить»).

### Общая информация (2–3 предложения)

```
Приложение позволяет администратору подключиться к экрану смарт-терминала
удалённо через браузер: видеть происходящее на экране в реальном времени и

### Преимущества (не более трёх)

```
1. Видит экран терминала и позволяет управлять им в реальном времени —
   не нужно выезжать на площадку ради простой настройки или диагностики.

2. Безопасно по умолчанию. Подключение требует двух ручных разрешений
   оператора на самом терминале (захват экрана и специальные возможности) —
   без них удалённый сеанс невозможен технически, а не только по правилам.

3. Работает через NAT и мобильный интернет. Терминал сам обращается к
   серверу — не нужен белый IP, проброс портов или VPN.
```

### Особые условия использования

```
Для работы нужен интернет на терминале. Первое включение требует один раз
подтвердить два системных разрешения Android непосредственно на терминале —
захват экрана и специальные возможности (эмуляция касаний). Без обоих
разрешений подключение невозможно технически. Каждый сеанс инициирует
администратор со своей стороны.
```

### Раздел «Как это работает»

```
Для кого

Для тех, кто обслуживает смарт-терминалы Эвотор удалённо: настройка,
диагностика неполадок, обучение оператора без выезда на площадку.

Как это работает

1. Установите приложение на терминал, укажите адрес сервера поддержки —
   он выдаётся один раз при подключении к сервису.
2. На терминале включите два разрешения: захват экрана и специальные
   возможности (эмуляция касаний) — оба запрашиваются самим приложением,
   подтверждаются один раз.
3. Администратор со своей стороны (в браузере) выбирает нужный терминал
   из списка подключённых и нажимает «Экран» — видео пойдёт в течение
   примерно 30 секунд.
4. Администратор видит экран терминала в реальном времени и может кликать
   по нему как по своему — терминал эмулирует эти нажатия сам.
5. Сеанс завершается закрытием окна просмотра или самим оператором на
   терминале в любой момент — приложение никогда не блокирует терминал
   и не мешает штатной работе кассы.

Что нужно для работы

• Смарт-терминал Эвотор с интернетом
• Разрешение оператора терминала на захват экрана и специальные
  возможности (выдаётся один раз при первом сеансе)
• Учётная запись администратора на сервере поддержки

Полная инструкция: ‹ссылка после публикации›

Поддержка

‹телефон›, ‹почта›, время работы ‹…›

### Видео

Требуется ссылка на видео о приложении. YouTube запрещён — только RuTube
или VK Видео.

Сценарий на 30–40 секунд:

```
1. Терминал с включённым приложением, экран «Регистрация выполнена» (5 сек).
2. Браузер администратора: список терминалов, один — «на связи» (5 сек).
3. Клик «Экран» → через несколько секунд появляется видео с терминала
   (10 сек).
4. Клик мышью по видео → на терминале видно, как нажатие происходит само
   (10 сек).
5. Закрытие сеанса — на терминале ничего не изменилось, касса как касса
   (5 сек).
```

## 4. Перед отправкой на ревью

- [ ] `app_uuid` получен, прописан в сборке (`EVOTOR_APP_UUID`)
- [ ] Проксирование включено, маска `https://remote\.ntrip\.host/.*` добавлена
- [ ] Бэкенд развёрнут на `remote.ntrip.host` и отвечает по HTTPS
- [ ] APK подписан release-ключом (не debug)
- [ ] Иконка, минимум три скриншота (в рамках терминала), видео
- [ ] Совместимость проверена и заполнена по факту, не «на все модели» без проверки
- [ ] Приложение проверено на живом терминале: регистрация, оба разрешения,
      реальный сеанс просмотра/управления от начала до конца
- [ ] Оферта на подписку переоформлена под новый продукт
- [ ] Контакты поддержки заполнены

Модерация занимает около пяти рабочих дней.
