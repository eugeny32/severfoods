# Презентация системы «СеверФудс»

`SeverFoods-presentation.pptx` — 24 слайда о продукте: терминалы на точках,
серверная часть с веб-интерфейсом, центр управления площадками. Производитель
ПО — ООО «Север».

## Как пересобрать

```bash
npm install pptxgenjs          # один раз
node build-presentation.js     # перезаписывает SeverFoods-presentation.pptx
```

Скрипт — единственный источник презентации: правки вносятся в него, а не в
готовый файл, иначе следующая сборка их затрёт. Если презентацию правили прямо
в PowerPoint, сохраните её под другим именем.

Все снимки экрана — с настоящего интерфейса, данные на них демонстрационные
(вымышленные ФИО и организации):

| Файл | Что на нём |

## Что заполнить перед показом

* Контакты ООО «Север» на последнем слайде (`‹укажите›`).
* Проверить, что версия и дата на титуле актуальны.

## Проверка вёрстки

LibreOffice в среде сборки не запускается, поэтому слайды проверялись не
глазами, а программно: границы слайда, отступы от края, вместимость текста в
рамках (с переносом по словам) и наложение текстовых блоков. Перед показом
откройте файл в PowerPoint и пролистайте — проверка геометрии не заменяет
живого просмотра, особенно на слайдах со снимками экрана.
