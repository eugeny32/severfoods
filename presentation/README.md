# Презентация системы «СеверФудс»

Два формата одного содержания:

| Файл | Что это |
|---|---|
| `SeverFoods-presentation.pptx` | Презентация для показа и правки в PowerPoint |
| `index.html` | Веб-версия: листается стрелками, печатается в PDF, открывается с телефона |

Веб-версия самодостаточна — картинки вшиты в файл. Её можно положить на сайт,
отправить письмом или открыть с флешки: ничего рядом не нужно.

```bash
python3 build-html.py    # пересобрать index.html (и web/artifact.html)
```

`SeverFoods-presentation.pptx` — 24 слайда о продукте: терминалы на точках,
серверная часть с веб-интерфейсом, центр управления площадками. Производитель
ПО — ООО «Север».

## Как пересобрать

```bash
npm install pptxgenjs          # один раз
node build-presentation.js     # перезаписывает SeverFoods-presentation.pptx
```

Скрипт — единственный источник презентации: правки вносятся в него, а не в
готовый файл, иначе следующая сборка их затрёт. Если презентацию правили прямо
в PowerPoint, сохраните её под другим именем.

## Что заполнить перед показом

* Контакты ООО «Север» на последнем слайде (`‹укажите›`).
* Проверить, что версия и дата на титуле актуальны.

## Проверка вёрстки

LibreOffice в среде сборки не запускается, поэтому здесь два своих инструмента:

```bash
python3 check.py SeverFoods-presentation.pptx      # геометрия и вместимость текста
python3 preview.py SeverFoods-presentation.pptx s  # отрисовка слайдов в s-01.png …
```

`check.py` ловит выход за границы слайда, отступы меньше 0.4″, текст, который
не влезает в рамку, наложение блоков друг на друга и на картинки, а также
растянутые изображения. `preview.py` рисует слайды картинками — этим они и
проверялись глазами.

Для верности измерений нужны метрически совместимые шрифты:

```bash
apt-get install -y fonts-crosextra-carlito   # метрики Calibri
```

Arial заменяется Liberation Sans, который обычно уже стоит.

## Шрифты

Заголовки — Arial, текст — Calibri. Это выбор по надёжности: Cambria, стоявшая
здесь сначала, есть не на всех машинах, и подстановка другого шрифта с иными
метриками ломала вёрстку — текст переносился иначе и «ехал» за рамки.
